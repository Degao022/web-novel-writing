## 📝 功能简介

这是一个网文创作skill，支持：

- ✅ 结合用户思路进行创新构思
- ✅ 起草小说大纲和世界设定
- ✅ 搜索各类素材，建立素材库
- ✅ 学习创作经验和技巧
- ✅ 撰写小说初稿
- ✅ 支持多类型：玄幻、都市、科幻、历史等
