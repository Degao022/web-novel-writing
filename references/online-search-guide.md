### 1.2 平台特定搜索

#### 起点平台（Qidian）
- 搜索技巧：`site:qidian.com [题材] 写作`
- 目标内容：作品简介、作者的话、书评区
- 提取重点：作者创作谈、读者反馈、热门元素

#### 番茄平台（Fanqie/番茄小说）
- 搜索技巧：`site:fanqie.com [题材] 创作` 或 `番茄小说 [题材] 写作技巧`
- 目标内容：作品热评、作者连载心得、番茄公众号文章
- 提取重点：
  - **推荐算法偏好**：番茄偏爱快节奏、爽点密集、开篇即高潮的作品
  - **章节长度要求**：建议 1500-2500 字/章（比起点略短）
  - **内容审核规范**：禁止内容详见 SKILL.md Q章节（平台规范）
  - **读者偏好**：碎片时间阅读，喜欢轻松、爽快、不烧脑的作品

#### 知乎（Zhihu）
- 搜索技巧：`[题材] 小说 怎么写 site:zhihu.com`
- 目标内容：写作技巧回答、创作经验分享
- 提取重点：高赞回答中的实用技巧、避雷指南

#### 豆瓣读书（Douban）
- 搜索技巧：`site:book.douban.com [书名] 评论`
- 目标内容：深度书评、作品分析
- 提取重点：作品优缺点分析、读者真实反馈

## 二、搜索操作流程

### 2.1 搜索素材流程（对应 S1 章节）

```
步骤1：明确需求
  → 用户指令："搜索[类型]素材"
  → 确认素材类型：历史架空/无限流/克苏鲁/...

步骤2：执行搜索
  → 使用 WebSearch 工具搜索
  → 关键词模板："[题材] 小说写作技巧 site:zhihu.com"
  → 或使用 WebFetch 直接抓取特定页面

步骤3：提取核心内容
  → 从搜索结果中提取：
    - 世界观设定技巧
    - 力量体系设计
    - 角色塑造方法
    - 经典情节模板
    - 读者偏好分析

步骤4：保存素材
  → 保存到 references/[类型]-materials.md
  → 文件结构：
    ```
    # [类型]素材库
    
    ## 一、世界观设定
    ## 二、力量体系
    ## 三、角色塑造
    ## 四、情节模板
    ## 五、读者偏好
    ## 六、经典作品参考
    ```

步骤5：更新 SKILL.md
  → 在"一、快速入口"表格中添加新类型入口
  → 在对应章节中添加引用链接
```

### 2.2 搜索技巧流程（对应 S2 章节）

```
步骤1：明确学习目标
  → 用户指令："学习[类型]写作技巧"
  → 确认学习重点：开篇技巧/爽点设计/角色塑造/...

步骤2：多渠道搜索
  → 知乎：搜索高赞写作技巧回答
  → 豆瓣：搜索经典作品深度分析
  → 作者博客：搜索创作谈、后记
  → 起点/番茄：搜索作者的话、连载心得

步骤3：提取可复用技巧
  → 提炼成结构化知识点
  → 标注来源和适用场景
  → 转化为可直接套用的模板

步骤4：更新 Skill
  → 如果技巧通用：更新 SKILL.md 对应章节
  → 如果技巧特定：创建 references/[类型]-techniques.md
  → 更新 changelog，升级版本号

步骤5：验证效果
  → 用新技巧创作测试章节
  → 检查是否符合预期效果
```

## 三、番茄平台专项指南

### 3.1 番茄平台特点

| 特点 | 说明 | 创作建议 |
|------|------|---------|
| **推荐算法** | 偏爱快节奏、高留存 | 开篇3章必须有强悬念 |
| **读者群体** | 年轻化、碎片化阅读 | 章节短小精悍（1500-2500字） |
| **内容偏好** | 轻松爽快、不烧脑 | 减少复杂设定，增加爽点密度 |
| **更新频率** | 日更2-3章效果最佳 | 保持稳定的更新节奏 |
| **互动机制** | 评论区活跃 | 章末可设置互动问题 |

### 3.2 番茄平台内容审核规范

> 详细规范见 SKILL.md Q章节（平台规范）

**核心禁忌**：
- ❌ 违反法律法规内容
- ❌ 低俗色情内容
- ❌ 血腥暴力内容
- ❌ 宣扬封建迷信
- ❌ 侮辱诽谤他人

**审核建议**：
- 开篇避免敏感话题
- 正文注意措辞尺度
- 定期检查已发布章节

### 3.3 番茄平台写作技巧（在线搜索重点）

**搜索关键词**：
- `番茄小说 写作技巧 site:zhihu.com`
- `番茄小说 推荐算法 揭秘`
- `番茄小说 开篇技巧`
- `番茄小说 日更技巧`

**提取重点**：
- 推荐算法的工作原理
- 提高留存率的方法
- 读者评论中的高频吐槽点（避雷）
- 热门作品的共性特征

## 四、搜索质量控制

### 4.1 信息源可靠性评估

| 来源 | 可靠性 | 适用场景 |
|------|--------|---------|
| 知乎高赞回答（1万+赞） | ⭐⭐⭐⭐⭐ | 写作技巧、经验分享 |
| 豆瓣深度书评（长评） | ⭐⭐⭐⭐⭐ | 作品分析、优缺点 |
| 起点/番茄作者的话 | ⭐⭐⭐⭐ | 创作心得、实战经验 |
| 作者个人博客 | ⭐⭐⭐ | 创作谈、写作方法 |
| 贴吧/论坛讨论 | ⭐⭐ | 读者反馈、热门话题 |

### 4.2 素材保存规范

**文件命名规则**：
- 素材库：`[类型]-materials.md`
- 技巧库：`[类型]-techniques.md`
- 平台指南：`[平台]-platform-guide.md`

**内容结构规则**：
- 必须标注来源（URL、作者、日期）
- 必须标注提取日期
- 必须分类清晰（世界观/力量/角色/情节/...）
- 必须提供可复用的模板或示例

**禁止事项**：
- ❌ 直接复制大段原文（侵权风险）
- ❌ 保存低质量内容（无实质帮助）
- ❌ 保存过时的平台规范（必须验证时效性）

## 五、常见问题

| 问题 | 解决方案 |
|------|---------|
| **搜索结果质量低** | 更换关键词、更换搜索源、使用更精确的搜索语法 |
| **提取的内容无法复用** | 转化为模板、增加示例、标注适用场景 |
| **保存的素材与现有冲突** | 优先保留更高质量的内容，标注冲突点 |
| **找不到特定类型的素材** | 扩大搜索范围、尝试相关类型、手动整理 |
