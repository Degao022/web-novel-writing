# 网文流派核心公式指南

---

## 一、玄幻 / 修仙流

**核心公式：** 废柴逆袭 → 境界突破 → 横扫同级 → 升级打怪

**读者核心期待：**
- 境界体系清晰可量化（要让读者能计算"主角还差多远才能碾压反派"）
- 每个大境界突破必须有正面描写，展现质的飞跃
- 丹药/功法/法宝要有层次感，低阶变高阶需要铺垫

**常见开局类型：**
1. 废柴型：被嘲笑→获逆天传承→打脸所有人
2. 穿越型：现代人穿入，携带超前知识/系统
3. 重生型：强者陨落重生年少，带记忆复仇+攻略
4. 系统流：游戏系统/签到系统/吞噬系统加持

**力量体系设计要点：**
- 等级数量：建议8-12级，不宜太少（无成长空间）也不宜太多（读者记不住）
- 主角突破节奏：前期快（每10章一境界），中期稳（每30章），后期每大境界是一个高潮
- 天才与废柴对比：同龄人修炼速度对比是最直观的爽点

**常用爽点：**
- 垃圾丹药/功法被主角发现真正价值
- 被赶出门派→回来时已是大能
- 对方轻视主角时，主角一招秒杀

**避坑：**
- 不要让主角在同一境界停留超过50章
- 反派实力要略高于主角当前实力（才有压迫感），但不能强太多（爽感消失）

## 二、都市异能 / 都市重生流

**核心公式：** 平民/落魄者 → 获得异能/重生记忆 → 打脸贵圈 → 执掌商界/政界

**读者核心期待：**
- 打脸要快、要狠、要当众
- 主角"装作普通人"然后突然亮出真实实力
- 美女/美男追求但主角淡定

**常见开局类型：**
1. 重生：商界/军界大佬重生年少，重新布局
2. 赘婿流：入赘豪门被鄙视→隐藏身份→震惊众人
3. 退伍兵：特种兵/雇佣兵回归都市，被误认为废物
4. 异能觉醒：普通人觉醒能力，进入异能者体系

**核心爽感场景模板：**
- 场景1（认亲）：被家族赶出→功成名就后被家族主动找上门
- 场景2（打脸）：反派当众羞辱→主角亮出更高身份
- 场景3（震惊）：女友/男友抛弃主角→发现主角才是真正大佬
- 场景4（护短）：有人欺负主角身边人→主角瞬间翻脸

**对白风格参考：**
```
反派："就凭你？保安都不如，敢在这里充大爷？"
主角微微一笑，掏出手机拨了个号码。
三分钟后，反派的老板亲自赶来，跪地道："陈总，是我管教不严，请您大人大量……"
```

**避坑：**
- 不要让主角沉迷于某个女性太久（读者易不耐烦）
- 打脸节奏：最多拖3章，必须出结果
- 主角要有明确的核心事业线，不能只打脸没目标

## 三、星际 / 科幻流

**核心公式：** 底层士兵/科学家 → 掌握核心科技/战术 → 崛起于战争 → 统一星际/打败外星威胁

**读者核心期待：**
- 宏观宇宙战争的震撼感
- 主角凭借超越时代的知识或战术逆转局面
- 机甲/战舰/星球要有细节描写

**常见开局类型：**
1. 穿越到星际时代，携带现代/未来知识
2. 被认为是废物的驾驶员，觉醒逆天天赋
3. 科学家/工程师身份，用知识改变战局

**战斗场景写法要点：**
- 宏观战场（舰队对决）：用数据和战略展现规模
- 微观战斗（机甲对战）：用速度、反应、技巧展现主角能力
- 必须有明确的"以少胜多"或"技术碾压"场面

**避坑：**
- 科技设定要自洽，不要前后矛盾
- 星际流的支线感情线建议简化，读者主要看战争爽

## 四、古言 / 历史穿越流

**核心公式：** 现代女/男穿越 → 身处低微 → 凭现代知识/手段崛起 → 权倾朝野/得到良缘

**读者核心期待：**
- 古代场景的精致感（服饰、规矩、权谋）
- 主角利用现代知识"开挂"（经济、医学、政治）
- 情感线要有张力，相爱相杀

**常见开局类型：**
1. 女穿：现代职场精英穿越为庶女/丫鬟
2. 男穿：穿越为皇子/谋士/落魄书生
3. 重生：原本悲剧收场，重来一次扭转命运

**权谋要素：**
- 皇位争夺：各方势力要清晰，主角选择队伍有理由
- 后宫/前朝：双线并进，相互影响
- 每个阴谋要有前置铺垫，不要无中生有的反转

**感情线节奏：**
- 前20章：相遇，有初印象（不必立刻喜欢）
- 20-60章：相处，摩擦中产生感情
- 60-100章：有情但有阻碍，虐恋期
- 100章后：确认心意，但外部威胁未解决
- 结局前：化解所有危机，圆满

**避坑：**
- 现代知识应用要合理，不能过于超前让读者出戏
- 感情线不能比权谋线更长

## 五、言情 / 甜宠流

**核心公式：** 普通女孩 → 遇到高冷/霸道男主 → 相处中融化 → 甜蜜HE

**读者核心期待：**
- 甜甜甜，糖分要高
- 男主要"外冷内热"，只对女主温柔
- 误会要有但不能太长，快速化解

**甜点场景必备清单：**
- 男主主动维护女主（当众护短）
- 深夜照顾/治疗场景（肢体接触）
- 醋意场景（男主对女主其他追求者明显不满）
- 节日/特殊时间节点的惊喜
- 哄人场景（男主低姿态求和）

**虐恋甜文节奏（先虐后甜）：**
- 前段：误会/身份差距/外部阻力→痛苦分离
- 中段：分开期间双方内心独白，读者知道两人都爱对方
- 后段：真相大白+和解+加倍甜

**避坑：**
- 甜宠文误会拖超过10章读者会弃书
- 女主不能软弱无能，需要有闪光点让男主"崇拜"
- 男主霸道但不能真的伤害女主（底线）
