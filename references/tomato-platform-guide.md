# 番茄平台创作指南

> 本文档为 `web-novel-writing` skill 的配套参考文件，提供番茄平台（Fanqie）的专项创作指导。

---

## 一、番茄平台特点

### 1.1 平台基本信息

| 项目 | 说明 |
|------|------|
| **平台名称** | 番茄小说（Fanqie） |
| **运营方** | 字节跳动 |
| **主要内容** | 免费阅读+广告变现 |
| **读者群体** | 年轻化、碎片化阅读、偏好轻松爽快 |
| **推荐算法** | 基于留存率、完读率、互动率 |

### 1.2 与起点平台的主要差异

| 对比维度 | 起点平台 | 番茄平台 |
|---------|---------|---------|
| **盈利模式** | 付费订阅 | 免费+广告 |
| **章节长度** | 2000-3000字/章 | 1500-2500字/章 |
| **节奏要求** | 相对舒缓，可接受慢热 | 快节奏，开篇即高潮 |
| **读者耐心** | 较高，愿意养书 | 较低，3章不爽就弃书 |
| **内容偏好** | 深度、设定复杂 | 轻松、爽快、不烧脑 |

## 二、番茄平台创作技巧

### 2.1 开篇技巧（前3章决胜）

| 技巧 | 说明 | 示例 |
|------|------|------|
| **直接冲突** | 第1章必须有明确冲突 | 主角被退婚→立刻反击，不拖延 |
| **金手指早现** | 第1-2章金手指必须出现 | 系统、传承、重生记忆，尽早到账 |
| **爽点前置** | 前3章至少1个小爽点 | 打脸、装逼、获得宝物 |
| **悬念钩子** | 每章结尾留悬念 | "他不知道，手机上正显示着..." |

### 2.2 节奏控制

**番茄节奏公式**：
```
开篇（1-3章）：冲突→金手指→小爽点
发展（4-30章）：升级→打脸→新地图
高潮（31-100章）：大事件→大突破→大打脸
```

**章节节奏检查表**：
- [ ] 每章有冲突/爽点/情感波动之一
- [ ] 每章结尾有钩子（悬念/疑问/新危机）
- [ ] 无连续3章无爽点（读者会弃书）
- [ ] 无超过5章的慢热铺垫（番茄读者没耐心）

### 2.3 章节长度建议

| 章节类型 | 建议长度 | 说明 |
|---------|---------|------|
| 开篇第1章 | 2000-2500字 | 必须足够吸引人 |
| 常规章节 | 1500-2000字 | 番茄最适宜长度 |
| 爽点章节 | 2000-2500字 | 打脸/突破需要足够篇幅 |
| 过渡章节 | 1000-1500字 | 尽量短，快速过渡 |

### 2.4 读者互动技巧

| 技巧 | 操作方法 | 效果 |
|------|---------|------|
| **章末提问** | "你们猜他会不会答应？" | 增加评论区互动 |
| **彩蛋章节** | 偶尔加个搞笑彩蛋 | 提高读者好感度 |
| **回复评论** | 作者的话回复热门评论 | 提高粉丝粘性 |

## 三、番茄平台推荐算法揭秘

### 3.1 核心指标

| 指标 | 权重 | 优化方法 |
|------|------|---------|
| **留存率** | ⭐⭐⭐⭐⭐ | 开篇3章必须抓人 |
| **完读率** | ⭐⭐⭐⭐⭐ | 每章结尾留钩子 |
| **互动率** | ⭐⭐⭐ | 章末提问、回复评论 |
| **更新频率** | ⭐⭐⭐ | 日更2-3章效果最佳 |

### 3.2 推荐流量池

```
第1波：初始推荐（500-1000人）
  ↓ 留存率>50%？
第2波：小量推荐（5000-10000人）
  ↓ 完读率>60%？
第3波：大量推荐（10万+人）
  ↓ 持续表现良好？
第4波：爆款推荐（100万+人）
```

### 3.3 提高留存的技巧

| 技巧 | 说明 |
|------|------|
| **前3章不断悬念** | 每章结尾留一个悬念，让读者忍不住看下一章 |
| **金手指早现早用** | 第1-2章金手指出现，第3-5章就用上 |
| **避免慢热铺垫** | 前10章不要大量铺垫，爽点要密集 |
| **章节长度适中** | 1500-2500字最佳，太长读者没耐心 |

## 四、番茄平台内容审核规范

> 详细规范见 SKILL.md Q章节（平台规范）

### 4.1 核心禁忌（红线）

| 禁忌 | 说明 | 后果 |
|------|------|------|
| ❌ 违反法律法规 | 危害国家安全、色情、暴力等 | 封号、法律责任 |
| ❌ 低俗色情 | 露骨性描写、性暗示 | 下架、封号 |
| ❌ 血腥暴力 | 过度血腥、残酷暴力 | 下架 |
| ❌ 宣扬封建迷信 | 详细描写算命、风水等 | 下架 |
| ❌ 侮辱诽谤他人 | 影射现实人物 | 法律纠纷 |

### 4.2 审核建议

| 建议 | 说明 |
|------|------|
| **开篇避免敏感话题** | 政治、宗教、社会敏感事件 |
| **正文注意措辞尺度** | 打斗描写不要过度血腥 |
| **定期检查已发布章节** | 平台会定期抽查已发布内容 |
| **注意读者举报** | 被举报内容会优先审核 |

## 六、番茄平台 vs 起点平台：双平台创作策略

### 6.1 内容适配策略

| 策略 | 说明 |
|------|------|
| **双平台不同版本** | 同一故事，番茄版节奏更快、更爽 |
| **章节拆分/合并** | 起点版2000-3000字/章，番茄版1500-2500字/章 |
| **开篇重写** | 番茄版开篇更直接、更爽快 |

### 6.2 时间安排

| 平台 | 更新时间建议 |
|------|--------------|
| **起点** | 固定时间更新（培养读者习惯） |
| **番茄** | 日更2-3章，分散在不同时间段 |
