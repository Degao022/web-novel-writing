# 分段规范（读者阅读习惯）

> 本文档定义网络小说正文的分段标准，基于《穿越后我绑定了毒舌系统》第21章风格总结。适用于所有章节的写作与润色。

---

## 一、核心原则

| 原则 | 说明 |
|------|------|
| **连贯情节不拆段** | 同一场景、同一动作的连续描写应合并为一段（2-4行），禁止逐句拆分 |
| **对话严格独立成段** | 每个人物的对话（含说话人动作描写）必须单独成段 |
| **系统提示独立成段** | 系统提示、面板数据等UI元素必须单独成段 |
| **去掉场景分隔线** | 不使用 `---` 作为场景分隔线，依靠段落自然过渡 |
| **段落长度适中** | 每段2-4行（约50-150字），过长或过碎均不合格 |

---

## 二、分段规则详解

### 2.1 对话分段（必须遵守）

```
"你就是陈洛？"           ← 对话独立成段

陈洛打量他们一眼，不紧不慢道：  ← 说话人动作可单独成段
"我就是，你们是铁拳帮的人？"

独眼龙一愣：               ← 对方反应可单独成段
"你怎么知道？"

"猜的。"                   ← 简短回答独立成段
```

**要点：**
- 每轮对话独立成段，不与其他内容混排
- 说话人的动作描写可包含在对话段内，也可单独成段（以可读性为准）
- 同一说话人的连续对话，若内容较长可分段，短对话不拆分

---

### 2.2 叙述描写分段

**连贯情节描写** → 合并为一段（2-4行）

✅ **正确示例（第21章风格）：**
```
暮春的风裹着麦香吹过村道，落雁村恢复了往日平静。田埂上的麦苗刚抽穗，农人们弯腰劳作的身影散在田野里，连往日里总蹲在村口嚼舌根的婆子们都少了动静。
```

❌ **错误示例（过度拆分）：**
```
暮春的风裹着麦香吹过村道。

落雁村恢复了往日平静。

田埂上的麦苗刚抽穗。
```

---

### 2.3 动作与心理活动

- **动作描写**：与对话分离时，可单独成段（1-2行）
- **心理活动**：简短心理可融入动作描写；较长心理活动可单独成段
- **系统提示**：必须独立成段，前后留空行

---

### 2.4 特殊元素处理

| 元素 | 处理方式 |
|------|---------|
| 系统提示 `[叮。...]` | 独立成段，前后空行 |
| 系统面板数据 | 独立成段，格式对齐 |
| 章末标记 `（本章完）` | 独立成段，前空一行 |
| 场景转换 | 依靠時間詞或地点词自然过渡，不用 `---` |

---

## 三、禁止事项

| 禁止 | 原因 |
|------|------|
| 逐句拆分叙述描写 | 破坏阅读连贯性，产生"碎碎念"感 |
| 使用 `---` 场景分隔线 | 不符合网络小说读者习惯 |
| 段落过长（>5行） | 手机端阅读体验差 |
| 对话与其他内容混排 | 降低对话辨识度 |
| 连续短段落（1-2字） | 显得内容注水 |

---

## 四、检查清单

完成每章后，按此清单校验：

- [ ] 所有对话是否独立成段
- [ ] 连贯情节描写是否合并为2-4行段落
- [ ] 是否去除了所有 `---` 分隔线
- [ ] 系统提示是否独立成段
- [ ] 段落长度是否适中（无过长或过碎）
- [ ] 场景转换是否依靠自然过渡

---

## 五、修改示例

### 修改前（错误分段）：
```
暮春的风裹着麦香吹过村道。

落雁村恢复了往日平静。

田埂上的麦苗刚抽穗。

---

但陈洛心里清楚，这只是暴风雨前的宁静。

陈霸那人睚眦必报。
```

### 修改后（正确分段）：
```
暮春的风裹着麦香吹过村道，落雁村恢复了往日平静。田埂上的麦苗刚抽穗，农人们弯腰劳作的身影散在田野里，连往日里总蹲在村口嚼舌根的婆子们都少了动静。

但陈洛心里清楚，这只是暴风雨前的宁静。陈霸那人睚眦必报，上次在村里丢了那么大脸，以他的性子绝不会善罢甘休，只是没想到，陈霸的动作竟这么快。
```
